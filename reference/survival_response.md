# Build a survival response from a clinical data frame

Build a survival response from a clinical data frame

## Usage

``` r
survival_response(data, type = c("rfs", "os", "dfs"))
```

## Arguments

- data:

  Data frame such as the included
  [clin_crc](https://gflab.github.io/clinstats/reference/clin_crc.md)
  dataset.

- type:

  Endpoint prefix: `"rfs"`, `"os"`, or `"dfs"`. The columns
  `<type>.delay` and `<type>.event` must exist.

## Value

A [`survival::Surv()`](https://rdrr.io/pkg/survival/man/Surv.html)
object.
