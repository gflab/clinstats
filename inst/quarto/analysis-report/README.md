# Analysis report template

A Quarto document with lab-style defaults for HTML and PDF output. Copy it
into a project with `copy_report_template()` or by hand, then edit the title,
author, aim, and data fields.

```r
clinstats::copy_report_template()
```

The example chunks use the bundled datasets and replace them with project
data. Rendering requires Quarto and the `clinstats` package.
